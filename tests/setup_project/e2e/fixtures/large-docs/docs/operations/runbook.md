# 运维手册

本手册列出夜间维护的全部步骤，按编号顺序执行。

夜间维护窗口的总体原则：所有步骤都在维护者本机执行，执行前确认没有其他终端正在写账本文件，执行中如果任何一步失败就停止后续步骤并保留现场，不要尝试手工修补 JSON；每一步的输出都追加到维护日志，日志文件按月轮换，旧日志保留十二个月后删除；如果某一步需要的时间明显长于平时（超过平时的三倍），先检查磁盘空间与文件系统错误，再决定是否继续；维护完成后在日志末尾写一行总结，包括开始时间、结束时间、执行的步骤编号与任何异常；维护期间禁止运行导入命令，因为导入会一次性追加大量条目并改变计数基线，若确需导入，放到维护结束后单独执行，并在下次维护前把新的计数写入基线；维护所用的 ledger-ops 工具版本必须与账本格式版本匹配，不匹配时先升级工具，不要用旧工具处理新格式的文件；如果维护被打断，下次从被打断的那一步重新开始，不要从第一步重做全部步骤，也不要跳过被打断的那一步；这些原则适用于下面所有步骤，单个步骤的说明里不再重复。

## 步骤 01：轮换日志

本步骤轮换日志，属于第 1 轮维护。执行前确认上一步已经成功结束并在日志中留下记录；执行时观察输出中的计数，与上次维护记录的计数比较，差异超过百分之十时暂停并人工检查原因。完成后把命令输出原样追加到维护日志，并记录耗时，便于下次比较。若本步骤失败，按总体原则停止后续步骤。

```sh
ledger-ops run --step 01
```
