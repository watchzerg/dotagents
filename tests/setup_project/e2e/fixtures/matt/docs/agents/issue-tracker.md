# 任务跟踪器（Issue Tracker）

本项目使用 Beads 保存票据、依赖、处理状态与讨论，通过仓库根目录下的 `bd` CLI 操作。

## 技能操作映射

- 获取相关票据：使用完整 Beads ID 读取详情、依赖与讨论。
- 发布票据：在 Beads 创建，每项可独立执行的工作对应一张票据，记录目标、范围、验收条件及相关文档链接。
- 查找待办：查询未关闭票据；选择执行对象时核对依赖与认领状态。
- 认领工作：开始实施前通过 Beads 的认领操作记录负责人。
- 更新进度：在原票据维护状态，讨论与证据记录到票据评论。
- 完成工作：记录结果、验证证据及未覆盖项，满足验收条件后关闭。
- 分诊：按 [标签映射](triage-labels.md) 设置 Beads 标签；标签不替代票据状态和依赖关系。

命令及参数以当前安装版本的 `bd --help` 和子命令帮助为准；支持时使用 JSON 输出，写入后回读确认。

## 规格与探索

使用探索技能组织工作时，以父票据记录总目标、已定结论和未决问题，以子票据承载调研、原型或实施任务，使用 Beads 依赖表达阻塞关系。子票据完成后，将结论及证据链接回父票据。

GitHub 远程用于代码托管，技能票据统一写入 Beads。远程同步按用户授权执行，本配置不触发同步。
