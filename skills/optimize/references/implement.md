# 实施与收尾

改写自 Matt Pocock 的 `implement-spec`（MIT 许可，<https://github.com/mattpocock/skills>，插件 `mattpocock-skills` 1.3.1）。改动：票据在合入集成分支时关闭，使续跑能从票据状态判断进度；收尾加上门禁、合入默认分支与出口检查；不开 PR，不推送。

票据不是步骤清单，是带阻塞关系的任务图，任何时刻都有一条**前沿**：阻塞方已全部关闭的票。目标是整份 spec 在一条**集成分支**上实现，再合入默认分支。

项目的 `docs/agents/testing.md` 有 implement-spec 覆盖规则时，把它与 `docs/agents/documentation.md` 的随交付同步一并遵守，并把两处链接传给每个实现、合并、修复子 agent。两者与本文冲突时，本主题文件的验证方式优先。

## 实施

1. **读 spec 与全部子票**，得到任务图和主题。读主题文件的验证方式。
2. **集成分支。** 从默认分支最新提交建 `optimize/<spec 编号>`，放在它自己的 worktree 里，主工作树留在默认分支；把分支名与基准提交写进 spec 评论。续跑时从评论取回，不重建。
3. **探查（可选）。** 多张票需要同一批背景时，派一个探查子 agent 把笔记写到仓库之外的目录，路径传给后续子 agent。
4. **派实现子 agent。** 前沿上的每张票一个，各自的 worktree 与分支，尽量后台并行。简报只给指针：spec 编号、票据编号、集成分支名、主题文件路径、上面的项目规则链接、探查笔记路径。每个实现子 agent：
   - 开始前确认 worktree 基于集成分支最新提交，不是就重置到它；认领票据。
   - 按主题文件的验证方式完成这张票。调用 `mattpocock-skills:tdd` 时，spec“测试决定”里的 seam 即已确认的 seam，不再向用户确认。
   - 把集成分支最新提交合入自己的分支，在合并后的代码上运行本主题的每票出口命令，检查退出码。
   - 报告：提交、运行过的命令与退出码、与票据的偏离。权限被拒或遇到阻塞时原样报告，停在原地。
5. **合并。** 每个实现子 agent 完成后派一个合并子 agent，把它的分支合入集成分支：冲突按两边票据的意图解决，文档冲突同样处理；合并后运行每票出口命令并报告退出码。退出码为 0 时主 agent 关闭该票；不为 0 时派修复子 agent，修到通过再关。
6. **推进前沿。** 关票后重新取前沿（Beads 为 `bd ready`），有新票可做就继续派，直到子票全部关闭。

## 收尾

每完成一步，在 spec 评论记一行“已完成：<步骤名>”，续跑时从第一个未记录的步骤开始。

1. **review。** 调用 Skill `mattpocock-skills:code-review`，固定点为集成分支的基准提交，spec 来源为这份 spec。两个轴的全部发现交给一个修复子 agent 一次改完；判断不改的发现连同理由记入报告的“代用户做出的决定”。修复子 agent 同时核对主题的修复约束：A1 用 grep 证明没有残留，`logs` 主题逐处对照命中清单并确认新增日志过 L5～L8。
2. **文档核对。** `arch` 与 `docs` 主题调用 Skill `docs-audit`，参数为基准提交（diff 模式）。它转出的票记入报告的“遗留票据”，不在本轮处理。
3. **最终门禁。** 默认分支有新提交时先合入集成分支。然后由主 agent 运行主题文件规定的集成分支门禁，并显式取退出码：

   ```sh
   just gate-full; echo "exit=$?"
   ```

   运行期间工作树保持不变。失败就派修复子 agent 后重跑；此后的任何改动都使上一次结果失效。因桌面会话锁定而失败时立即停止并报告。
4. **合入默认分支。** 在默认分支合并集成分支。不推送。
5. **关闭 spec。** 关闭前确认子票全部关闭。
6. **清理。** 删除本轮的全部 worktree、票据分支与集成分支。
7. **出口检查。** 运行下列命令，输出原文写进报告：

   ```sh
   git worktree list
   git branch
   git status --short
   bd list --all --parent <spec 编号>
   bd show <spec 编号>
   ```

   通过的标准：worktree 只剩主工作树，分支不含本轮建的任何分支，工作树干净，spec 与子票全部关闭。
