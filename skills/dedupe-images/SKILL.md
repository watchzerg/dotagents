# 图片库去重

判定与执行全部由脚本 `scripts/dedupe_images.py` 完成，本 skill 只负责调用、展示计划、取得确认和转述结果。需要 `python3` 为 3.14+，只用标准库；支持 macOS 15+（系统自带 `/usr/bin/trash`）与 Linux（FreeDesktop 回收站）。

## 步骤

1. **确定总目录**：取用户给出的路径；没给就问，不猜。脚本只处理它的一级子目录里的直接文件，不递归，也不处理总目录本身的文件。
2. **生成计划**：计划文件写到临时目录，不写进图片库。

   ```sh
   python3 "<skill目录>/scripts/dedupe_images.py" plan "<总目录>" --out "<临时目录>/dedupe-plan.json"
   ```

   plan 不改动任何文件。把脚本输出的摘要原样转给用户：每个子目录删除与改名的数量（改名包括单独存在的副本，如目录里只有 `a (3).jpg` 时改为 `a.jpg`）、待释放体积、需人工确认清单、读取出错项。用户要看具体文件时，从计划 JSON 的 `dirs[].groups`（`keep`、`remove`、`rename_to`）中摘取。
3. **等待确认**：明确问用户是否执行，得到肯定答复才继续。需人工确认项（同名同体积但内容不同）脚本不会删除，只列给用户自行查看；不要打开图片做对比。
4. **执行计划**：

   ```sh
   python3 "<skill目录>/scripts/dedupe_images.py" apply "<临时目录>/dedupe-plan.json"
   ```

   apply 会逐个复核计划中的文件，计划之后有变动的组整组跳过。把移入回收站的数量与体积、改名数，以及每个跳过项和失败项如实转述；退出码 1 表示有失败项，2 表示计划不可用或平台不支持（此时未删除任何文件）。

## 约束

- 不手工删除、移动或改名图片，不编辑计划 JSON；用户想调整范围时，改总目录后重新运行 plan。
- 用户确认之后目录又有改动，或距 plan 已久，先重新运行 plan 再执行。
