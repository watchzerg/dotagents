# Commit

将现有变更提交为一个本地 commit，保持简短、直接。

1. 确认当前仓库，查看 staged、unstaged 和 untracked 状态以确定提交范围；不默认读取 Git diff。
2. 按用户指定范围暂存；“所有变更”或单独 `/commit` 默认包含当前仓库全部未忽略变更，不限于本轮修改。无变更则简短告知并结束。
3. 优先根据当前 session 上下文中已完成的修改生成简洁的 commit message；即使本次提交包含其他 session 的修改，也无需补齐其摘要，不为此读取或核对 Git diff。只有当前 session 基本为空、缺少可用于总结修改的有效信息时，才读取必要的 Git diff 来概括变更，不追查实现。遵循项目约定；无约定时使用简体中文。不把计划写成已完成，不虚构验证结果，不为措辞反复推敲，不再次确认，直接 commit。
4. 回读提交结果与工作区状态，简短报告 commit hash、摘要及是否有剩余变更。

## 边界

- 不修改代码或文档，不做 review、文档一致性检查、测试、lint、格式化或构建；不因提交而重跑已有验证。
- 不 push、不操作 tracker、不切换分支、不拆分提交、不 amend 或改写历史。
- 保留 Git hooks；失败时报告具体阻碍，不绕过 hooks 或擅自修复项目。
- 遇到冲突或明显凭据文件等实际阻碍时暂停说明；不扩展成全面审计。
