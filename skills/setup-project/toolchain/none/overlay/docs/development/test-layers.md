## 分层与资源边界

测试归属由目录、target 或 runner 与门禁入口固定，不由单次任务临时判断能否并行。

| 层级 | 准入 | 资源要求 |
| --- | --- | --- |
| core | 单元测试和轻量、结果确定的测试，秒级完成；不启动真实服务、数据库、浏览器或桌面会话，不执行 E2E | 不依赖共享可变状态、固定端口、桌面焦点或共享浏览器 Profile；可跨 worktree 并行 |
| full | 重型测试、真实基础设施集成、E2E 与需要独占资源的测试，即使已隔离也按验证范围归入；需要浏览器的测试以开发依赖引入 Playwright，用自带 Chromium、headless、每个测试独立 context | 尽量隔离；无法隔离的资源经主机锁串行；成功、失败、取消路径都清理自身资源 |

core 的准入看 fixture、子进程和输出路径的实际副作用，不以“当前恰好没冲突”为据；新增真实服务、共享状态或显著运行成本时重新分类。
