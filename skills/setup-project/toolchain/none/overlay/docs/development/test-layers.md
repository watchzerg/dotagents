## 分层与资源边界

测试归属由目录、target 或 runner 与门禁入口固定维护，不由单次任务临时判断能否并行。

| 层级 | 准入 | 资源要求 |
| --- | --- | --- |
| core | 单元测试和轻量、结果确定的测试，秒级完成；不启动真实服务或桌面，不执行 E2E | 不依赖共享可变状态、固定端口、桌面焦点；可跨 worktree 并行 |
| full | 重型测试、真实基础设施集成、E2E 与需要独占资源的测试；即使已隔离也按验证范围归入 | 尽量隔离；无法隔离的资源由统一入口串行使用；成功、失败、取消路径都清理自身资源 |

<待填 按需：本项目各层的目录、target 或 runner 选择范围，以及它们被哪个 just 入口收录>

core 不以"当前恰好没冲突"作为准入证据；新增真实服务、共享状态或显著运行成本时重新分类。不得通过 skip、收集过滤或弱化断言让门禁通过，零匹配不是通过。新增或移动的测试必须被对应入口自动发现，并被无筛选的 `gate-full` 收录。
