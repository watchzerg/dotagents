# 调研索引

本目录保存技术比较、实验、验证证据及其限制，按记录时点阅读，永不改写、不归档；被它链接的页面移动或拆分时只改链接目标。结论采纳后更新当前正文或新增 ADR，证据保留原样。验收记录放 `acceptance/`，文件名带日期；同一主题再做一轮时另建文件，不改旧记录。

新增文件必须在本页登记，未登记的文件视为不存在，`docs-check` 校验本目录每个文件都被本页链接。状态只写在本页，不回头改调研文件：

- **现行**：结论仍是当前依据，尚未写进正文。
- **已吸收**：结论已写进当前正文或 ADR，“结论与去向”给出链接；日常以正文为准，只在追溯证据时读。
- **已被取代**：有更新的调研或决定，“结论与去向”链接到取代它的那一篇。
- **一次性记录**：只对当时那次操作有意义，如验收记录。
