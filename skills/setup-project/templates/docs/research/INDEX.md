# 调研索引

本目录保存技术比较、实验、验证证据及其限制，属于[历史证据](../agents/documentation.md#三态规则)。结论采纳后写进当前正文或新增 ADR，证据保留原样。验收记录放 `acceptance/`，文件名带日期；同一主题再做一轮时另建文件。

每个文件都在本页登记（`docs-check` 校验）。状态只写在本页：

- **现行**：结论仍是当前依据，尚未写进正文。
- **已吸收**：结论已写进当前正文或 ADR，“结论与去向”给出链接；只在追溯证据时读。
- **已被取代**：“结论与去向”链接到取代它的调研或决定。
- **一次性记录**：只对当时那次操作有意义，如验收记录。
