# 项目初始化

本 skill 安装在目标机器的用户级，供各项目复用。用户需要初始化新项目时，先进入目标项目根目录，再调用本 skill。初始化目标始终是调用时当前工作目录所在的项目；执行脚本时保持该工作目录，skill 的安装目录仅用于定位脚本和配套资源。

当前仅阶段 1.1 可执行。用户请求初始化项目时执行该步骤，完成后说明后续步骤尚未实现并停止；用户仅要求讨论时保持只读。其余阶段保留讨论范围，待确定具体行为后再实现。

## 阶段 1：前置条件

### 1.1 初始化 Beads（已确定）

在目标项目根目录调用本 skill，保持当前工作目录：

```sh
python3 "<skill目录>/scripts/init_beads.py"
```

脚本失败则报告错误并中止；成功后报告初始化或跳过结果。首次 `bd init` 的自动 Git commit 属于已确认行为。

### 1.2 检查 Matt Pocock skills 设置（待讨论）

确认 `setup-matt-pocock-skills` 的执行情况；需要时提醒用户先执行，再重试本 skill。确认方式及重试条件后续讨论。

## 阶段 2：文档结构创建（待讨论）

按个人模板建立逐层发现的文档结构，例如 `AGENTS.md → INDEX.md → ARCHITECTURE.md → 模块文档`。

具体文件名、路径、层级职责与正文内容后续讨论。

## 阶段 3：项目依赖初始化（待讨论）

1. 询问选择 uv 或 Bun，初始化对应配置文件，跑通 install，并将工具链约定写入项目文档。
2. 创建 `justfile`，提供基本的 `gate-core` 与 `gate-full`，并将测试分类与测试执行约定写入项目文档。

依赖范围、命令定义、门禁边界及文档落点后续讨论；配置、命令和对应文档作为同一项能力一起落地。
