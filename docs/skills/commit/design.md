# commit 设计说明

## 关键决策

- **标题限短，细节进正文**（2026-11-23）：Claude Code 每个新会话都会注入 `git log --oneline` 最近 5 条的标题，本 skill 也读同样的单行日志作为 message 参考。本仓库之前把整段说明写在标题里，5 条标题约占 1K token 常驻上下文，而且新提交会照着长标题写下去。改为标题约 50 字以内、细节放正文；明确不照搬旧的长标题，避免示例自我延续。
- **只允许用户调用**（2026-11-24）：设 `disable-model-invocation: true`，description 不再常驻上下文，只作给人看的一行摘要。代价是“提交所有变更”这类自然语言不再触发，需输入 `/commit`；没有其他 skill 调用本 skill。

## 待验收

- 下一次 `/commit` 产出的标题是否简短、正文是否承接细节。
