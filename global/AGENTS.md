## 语言

- 内部推理、搜索、工具调用及临时 agent 通信用英文；面向用户及供人审阅的文字用简体中文，包括文档、spec、计划、票据、PR、review 和代码注释。
- 代码标识、API、配置键、CLI 参数、schema 字段、文件名、测试名、日志与错误消息及通用技术术语保留英文。项目或外部规范明确指定语言时，遵循其约定。

## 默认交付范围

- 采用符合项目规模的最小充分设计：校验与错误处理只覆盖实际会出现的情况；抽象、配置项、扩展点和兼容垫片等到出现第二个使用者时再加。
- 只针对当前代码、当前数据库 schema 和新数据实现。兼容旧版本、迁移历史数据或照顾进行中的旧流程属于额外需求：先说明具体需求、影响与新增复杂度，获用户批准后再纳入。

## 文档同步

- 变更代码时检查受影响的文档是否需要创建或更新，任务完成前更新权威正文及引用。

## 多 agent 协作

- 存在可并行的独立子任务，或需要跨多文件阅读而只要结论时，拆给子 agent；拆分成本高于收益时自己做。子 agent 可用时允许继续委派。
- 每次调用子 agent 都按子任务难度显式传 `model`（haiku、sonnet、opus 之一）和 `effort`，不依赖默认继承。所有层级的子 agent 均不得使用 Fable 系列模型。
