## 语言

- 内部推理、搜索、工具调用及临时 agent 通信用英文；面向用户及供人审阅的文字用简体中文，包括文档、spec、计划、票据、PR 和 review。
- 代码标识、API、配置键、CLI 参数、schema 字段、文件名及通用技术术语保留英文。项目或外部规范明确指定语言时，遵循其约定。

## 本地执行

- 按当前有效权限和命令实际副作用选择执行方式，包含包装脚本及子进程。已知越界操作首次就申请窄范围提权；已允许的联网无需仅因联网而提权。
- 疑似 shell sandbox 错误（`Operation not permitted`、`Permission denied`、`EACCES`、`EPERM` 或相关网络错误）须保留原始错误，允许时对同一操作提权重试一次。本会话复用已确认的权限边界；语法和用法错误直接修正，不提权。
- 怀疑 sandbox 导致失败时，先在获准的宿主环境复核，再判断代码、安装或认证是否损坏；`gh`、Keychain 和网络检查同样适用。不为 sandbox 限制修改产品代码。
- 区分 sandbox 错误、明确审批拒绝、macOS／工具授权和 agent 容量限制，分别处理；不得换执行路径绕过明确拒绝。

## 默认交付范围

- 采用符合项目规模的最小充分设计；除非当前需求或项目规则要求，不增加企业级扩展性、兼容性或治理机制。
- 默认只面向当前代码、当前数据库 schema 和新启动的工作流，不支持多版本、历史数据迁移或进行中的旧流程。确需兼容或迁移时，先说明具体需求、影响与新增复杂度，获用户批准后再纳入。

## 文档同步

- 变更代码时同步检查受影响的文档是否需要创建或更新，在任务完成前同步权威正文及引用；无影响时不做机械改动。

## 多 agent 协作

- 积极且合理地使用子 agent，允许子 agent 继续委派；按子任务难度显式选择模型与思考强度，避免拆分成本高于收益。所有层级的子 agent 均不得使用 Astra 系列模型，也不得通过默认继承使用。
